# Day 036｜営業日数カウンター

> 100日100プロダクトチャレンジ Day 036（2026-09-11）／カテゴリ: 日程・納期計算ツール

## これは何か

2つの日付を入れると、土日と祝日を除いた「本当の営業日数」を自動で数えるツール。あわせて「今日から◯営業日後」がいつになるかも、曜日付きですぐ分かる。ブラウザで開いて日付・数字を入れるだけで動く。インストール不要・保存機能なし。

## 解決する困りごと

- 想定利用者: 「営業日で○日以内に発送・納品」と案内する事業者・担当者
- 困りごと: 祝日を数え漏らして、納期の約束がズレそうになった（発送・見積回答の締切が「○営業日後」で決まっているのに、カレンダーを見ながら土日を手で数えて、祝日を数え漏らしてしまう場面を想定）
- 解決方法: 2つの日付の間の営業日数（土日祝を除く）を自動で数える。加えて「今日から○営業日後」の日付も即座に出す

## 使い方

```bash
# ビルド不要。index.html をブラウザで開くだけ
start index.html
```

1. カードA「期間で数える」に開始日・終了日を入れる。営業日数・うち土日・うち祝日が自動で出る
2. カードB「今日から◯営業日後を知る」に営業日数を入れる。曜日付きの日付が自動で出る
3. 期間が2026年以外を含む場合は「祝日は未判定」の注記が出て、土日のみを除外して計算する

## 主な機能

- 機能1: 期間の開始日・終了日を入力すると、土日祝を除いた営業日数と内訳（土日日数・祝日日数）を表示する
- 機能2: 2026年の祝日18日を内蔵し、期間が2026年以外を含む場合は「祝日は未判定」と明記して土日のみで計算する
- 機能3: 今日から指定した営業日数後の日付を、曜日付きで計算して表示する
